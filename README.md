# Trinity Invest

Projeto de um site com utilitários para investimento. No momento há apenas uma calculadora de juros compostos.

## Calculadora de Juros Compostos

Permite calcular o rendimento de investimentos a partir das seguintes entradas: aporte inicial, aporte mensal/anual, juros mensal/anual e período. E devolve o montante final, o montante investido e o montante em juros.
